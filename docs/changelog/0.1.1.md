# 0.1.1 — 2026-04-03

A CLR-interop hardening release. The bulk of the work is making classes, nullable types,
and precompiled packages behave the same on the IL backend as on the C# backend.

## Added

- **Mutable properties and nullable value types** on class fields, and `set!` inside
  method bodies for mutating them.
- **Opt-in init-only property setters** on class declarations.
- **Generic `new`** and **`out` parameter** support for CLR interop.
- **`null` literal**, for interop with APIs that expect it.
- **Nullable widening, polymorphic equality, implicit boxing**, and enum / static field
  access.
- **Type-annotated `let` bindings**, usable to upcast a value.
- **`Object` boxing alias**, fully-qualified `Task` support, and `double`/`float`
  conversions.
- **Async class methods.**
- **`string->int`** conversion builtin.
- **`test-case-async` and `theory-case-async`** in ZUnit.
- **`test-dependencies`** in the package manifest, and a **`zs init`** command with a
  manifest serializer.
- Macros can now generate type definitions (records, unions, classes) — covered by a new
  example.
- **Version bump script** covering all project manifests.

## Changed

- The **pipe operator is no longer a special form** — it is a `syntax-rules` macro in the
  stdlib.
- **The package cache is now required for builds.** `--no-cache` and source-module
  embedding were removed.
- CLI restructured into per-subcommand static classes.
- `PackageTester` extracted from `TestCommand` so package test runs resolve dependencies
  properly; the class-based module-injection hack it relied on was removed.

## Fixed

- IL backend: nullable reference types, boxing, and async state machines.
- IL backend: async methods, struct types, and generics coming from precompiled
  assemblies.
- IL backend: property resolution on nullable receiver types.
- IL backend: stack imbalance for mixed Unit/value branches in `if` and `match`, and in
  library assembly emission.
- IL backend: static property lookup, method resolution, and `import-clr` splitting.
- `ClassDecl` was dropped during library compilation — classes now make it into library
  assemblies, with correct IL type mapping.
- Cross-assembly interface subtype checking.
- Precompiled package resolution during test compilation; only class-containing modules
  are marked precompiled, which fixed a stdlib test regression.

## Diagnostics

- `IlTypeMapper` now warns when it falls back to `object` instead of silently widening.
