# 0.1 — 2026-03-31

First tagged release. Everything below was built from scratch between 2026-03-17 and the
tag, so this entry describes the language and toolchain as they first existed rather than
a delta from a prior version.

## The language

- **S-expression Scheme dialect compiling to .NET 10**, with Hindley–Milner type
  inference, unification, and generalization (`TypeInferer`, `Unifier`, `Substitution`,
  `TypeEnv`).
- **Core forms**: `define`, `lambda`, `let`, `let*`, `if`, `begin`, `match`,
  `define-record`, `define-union`, `module`, `namespace`, `import`, `export`.
- **Pattern matching** with an exhaustiveness checker over union cases.
- **Result / Option / Error** types with `try` / `?` propagation and a `catch` form;
  later in the cycle these moved out of the C# runtime and into the ZScheme stdlib.
- **Scheme-style booleans** — `#t` / `#f` replaced the initial `true` / `false` literals.
- **Polymorphism**: `^a` type-variable syntax, constrained type variables for arithmetic
  operators, generic constraints via `:where` (including `unmanaged` and `default`).
- **Hygienic macros** via `syntax-rules`, with macro definitions cached in precompiled
  packages.
- **Async**: `define-async` and `await`, with real async state machines on both backends;
  `await` outside an async context is now a compile error.
- **Variadic functions**, plus `list`, `array`, and `map-of` moved out of the compiler and
  into stdlib varargs functions.
- **Tuples** and `values`.

## CLR interoperability

- `import-clr` for static, instance, and generic members, plus namespace imports that
  lower to `using` directives.
- `(new TypeName args...)` for construction, `(raise expr)` for throwing, `(@ ...)` for
  .NET attributes, `(object ...)` for anonymous interface implementations.
- `(class ...)` and `(interface ...)` for declaring instantiable classes and .NET
  interfaces, with inheritance (`:open`), `super` calls, and explicit constructors —
  supported by both backends.
- `(with-handlers ...)` for catching .NET exception types by type.
- CLR subtype support in the unifier, CLR arrays, instance property setters, and instance
  indexer sets.
- `raise` is constrained to `System.Exception` subtypes.

## Backends

Two code generators reach feature parity over the cycle:

- **C# emitter** — modules become static classes, type declarations nest inside them,
  `let` lowers to `var` declarations rather than IIFEs, `using` directives are deduped.
- **IL emitter** — went through three implementations. The hand-rolled emitter came
  first, then Mono.Cecil (`--backend cecil`) which became the default and absorbed the
  original, and finally an AsmResolver-based emitter that replaced Cecil entirely and
  took the `IlEmitter` name. AsmResolver was moved to 6.0.0-rc.1 for .NET 10.
- The separate `ZScheme.Runtime` library was removed; runtime types are emitted inline and
  the stdlib binds real CLR types directly instead of going through wrapper types.

## Standard library and packages

- `.zspkg` package manifests with NuGet and ZScheme dependency resolution; NuGet is
  resolved through direct V3 API calls rather than shelling out to the .NET CLI.
- `packages/stdlib` — `option`, `result`, `error`, `core`, `list`, `vector` (renamed from
  the earlier `Vector` naming), `map`, `string`, plus mutable collection modules.
- `packages/zunit` — xUnit-backed testing framework with `test-case`, `test-suite`, and
  `theory-case` macros for parameterized tests.
- `packages/http` — HTTP client bindings.
- Precompiled module cache scoped under `~/.zscript`, with cached stdlib and zunit for
  fast builds.

## Tooling

- **CLI**: `compile`, `build`, `install` (renamed from `pack`), `test`, `run`, `repl`,
  `generate-project`.
- **REPL** moved into the compiler library behind an `IReplConsole` abstraction.
- **LSP server** plus editor extensions for VS Code, Zed (Tree-sitter grammar), Sublime
  Text, and JetBrains Rider/IntelliJ.
- **Serilog debug logging** threaded through the pipeline, CLI, and both emitters, exposed
  via `--debug` on the build scripts.
- Build/test scripts unified on cross-platform PowerShell (`pwsh`); the bash variants were
  dropped.
- Git SHA and tag embedded into the compiler build and generated C# output.

## Notable renames

- The project was renamed from **ZScript** to **ZScheme** near the end of the cycle.
- Published module functions moved from a flat `Program` class into module-named classes,
  and package namespaces became per-module CLR namespaces.
- Top-level statements now require an explicit `main`; files with top-level definitions
  require a `(module ...)` declaration.
