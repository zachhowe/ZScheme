# 0.1.3 — 2026-04-04

Standard library growth plus a large IL/C# emitter readability refactor.

## Added

- **`cond` macro** in the stdlib (and a fix to bracket-list macro patterns it depended on).
- **String module additions**: `string/equals?`, `string/empty?`, `string/starts-with?`,
  `string/ends-with?`.
- **`datetime` and `task`** CLR import modules in the stdlib.
- **Concurrent collection classes** in the stdlib.
- **Auto-install packages from source on cache miss** — a missing cached package no longer
  fails the build.
- **Detailed debug logging** across the compiler pipeline and both code generators.
- Test coverage collection in `run-all-tests.ps1`.

## Changed

- **Published binaries renamed to `zs` and `zs-lsp`.**
- **The package cache is now scoped by compiler version**, so a compiler upgrade no longer
  reuses stale artifacts.
- `IlEmitter` split into separate `Emit` / `Define` / `Resolve` files, and `CSharpEmitter`
  into a separate `Emit` file, for readability.
- Editor support updated for `#t` / `#f`, `(with-handlers ...)`, and `(set! ...)`.
- Mock testing guidelines rewritten to use ZScheme rather than C# examples.
