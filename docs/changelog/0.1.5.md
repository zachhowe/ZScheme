# 0.1.5 — 2026-04-15

A short release adding record update syntax and value types.

## Added

- **`(with ...)`** — copy-with-updates for record values.
- **`(struct ...)`** — declares a .NET value type.
- Both forms are documented in the syntax reference and highlighted as keywords in the
  editor grammars.
- `generate-project` is now package-aware and emits a test project and a `.slnx`.

## Fixed

- **Class methods can now call sibling methods and module-level defines.**
- **Async functions with no `await`** now have their bodies wrapped in a `Task` instead of
  producing invalid output.
- Value-type generic arguments are widened to `Object` when invariance forces it.
- Regression tests added for the async-without-await wrapping and class sibling calls.
