# 0.1.6 — 2026-05-05

The fuzzer release. A differential fuzzer (`zs-fuzz`) was introduced mid-cycle, and roughly
two thirds of the 120 commits in this release are correctness fixes it found — mostly in
the IL backend, mostly around closures, pattern matching, async, and object expressions.

## Added

- **`zs-fuzz`, a differential fuzzer** — generates random ZScheme programs and checks the
  C# and IL backends agree, via compile, `ilverify`, and diff-execution oracles. Cases run
  in parallel across CPU cores. Generator coverage was expanded incrementally through the
  cycle to include:
  - `match`, nested and constructor patterns, recursion, closures, float expressions
  - generics (including non-`Int` type arguments), stdlib imports, auxiliary modules
  - `begin`, `values`, `with`, partial application, `raise` + `with-handlers` (including
    multi-handler forms)
  - classes, interfaces, inheritance, object expressions
  - stdlib `Array` and `Map`, CLR interop bindings
  - async/await, `let*`, mutual recursion, mutation, `cond`, pipes, `slist`, recursive unions
  - structs, attributes, `:where` clauses, variadics, macros, wide primitive types
- ZUnit **migrated from xUnit v2 to v3**; `PackageTester` now awaits `Task`-returning tests
  and discovers `theory-case` tests.
- **`IrNode` carries a `SourceSpan`**, so codegen diagnostics report source locations.
- Compiler logs are tagged with `SourceContext` via `ForContext<T>`.
- Package manifests split their build section into nested `main` / `test`.

## Changed

- **Class and object methods must use `define` / `define-async`.**
- **Class and field flags migrated from `:keyword` to `#:keyword`.**
- Type variables render with distinct `^a` / `^b` names rather than repeating.
- **Unreachable `with-handlers` clauses are rejected at compile time.**

## Fixed — language and type inference

- Let-generalization subtracted environment free variables and shielded `ForAll`-bound
  variables, fixing over-generalization.
- `(super ...)` arguments are unified against the base class constructor's parameters.
- Substitution is applied under `With`, `SetField`, `SuperMethodCall`, and to
  `ObjectExpr` / `ClassDecl` constructors.
- Object-expression method bodies unify with their declared return annotation.
- Free numeric constrained type variables default to `Int` during resolution.
- Macro expansion recurses into `BracketList` contents.
- Codegen emitted no body for modules containing duplicate-named functions.

## Fixed — IL backend

- Closures: free-variable analysis now recurses into all compound IR nodes; imported
  modules' lambda closures nest under their own type; lambdas inside class methods that
  touch fields capture `this`; captured delegate fields resolve in `EmitCall`.
- Object expressions: constructors capture outer-scope references; module-scope references
  are excluded from captures and capture types preserved; closure analysis descends into
  object expressions; nested capture arguments resolve through `EmitVar`; `ZType` is
  recovered for captures sourced from locals and class fields; top-level functions shadowed
  by class fields are not captured; class fields shadowed by module functions are.
- Pattern matching: nested constructor patterns; non-`Variable` sub-patterns inside tuple
  patterns; tuple-pattern `Item` field references anchored on the closed `ValueTuple`;
  records and structs; generic struct case types tagged as value types; float literal
  patterns (both backends).
- Exceptions: `with-handlers` hoisted out of expression position; catch regions made
  contiguous; the fat EH section format is forced past 20 catch handlers; `super` args and
  field-set values containing `with-handlers` are spilled in constructors; `and`/`or`
  short-circuiting is preserved when the hoister A-normalizes.
- Async: await-point analysis recurses through all compound IR nodes and into the awaited
  expression; branching across try regions in state machines; underscore `Let`s are not
  hoisted; `with-handlers` is wrapped in an async lambda when the body awaits; await-in-catch
  is lifted out of the catch region; awaits are hoisted to let-bindings before
  state-machine lowering.
- `InitLocals` set on all method bodies; unordered float comparison for `<=` and `>=`;
  `callvirt` no longer used for value-type struct property access; declaring-type tokens
  closed for in-type field refs; generic instances closed when emitting record constructors;
  user-defined classes resolve in `ClrNew`; user-type instance calls resolve via
  `TypeDefinition`; indexer resolution for types with a non-default indexer name;
  let/match-bound locals resolve correctly in class method bodies; `and`/`or` short-circuit.
- Classes with explicit constructors route through `ClrNew` rather than `RecordNew`;
  class fields are `protected` so subclasses can read them.

## Fixed — C# backend

- Unreachable match arms pruned; scrutinee types propagated through nested patterns and
  into tuple sub-patterns; union-case scrutinees widened to their IR type; unreachable
  `_ =>` fallback suppressed for record-pattern matches.
- Compile-time-constant arithmetic wrapped in `unchecked`; `Int32.MinValue` emitted as
  `int.MinValue`; unary operands, negative-literal receivers, and `switch`/`await`
  receivers parenthesized.
- Lambda delegate types cast when emitting an IIFE; `default` generic constraint skipped;
  union type-param constraints propagated to case-derived records.
- Free type variables default to `int` (not `object`) across all emission paths, including
  object-expression captures, with a constraint-satisfying default substituted where one
  is required.
- Explicit type arguments emitted at call sites for generic functions; out-params detected
  for static `import-clr` with an explicit type annotation (and skipped when the annotated
  import returns a non-tuple); type substitution fixed for generic CLR `new` and out-params.
- `_` let bindings emit as discard assignments; `set!` emits as a bare assignment so it
  works in statement position; Unit-typed `(begin ...)` discards emit as bare statements;
  `!` sanitized in identifiers.
- Generic type arguments passed when lowering `map->mutable-map`; element types of empty
  variadic packs reconciled with call-site type arguments.

## LSP

- Hover fixed (including on multi-line `define` names); NuGet-backed CLR types resolve in
  `import-clr`; `.zspkg` manifests parse through `ManifestParser`; test-dependencies and
  default-module aliases resolve. Test coverage grew from 12 to 59 tests.
- Spurious "exports X but it is not defined" warning for macros fixed; exporting
  `syntax-rules` literals no longer warns.
