# 0.1.2 — 2026-04-03

A small follow-up to 0.1.1, mostly interop fixes and internal cleanup.

## Fixed

- **Interface subtyping, nullable boxing, and `Task<T>` await.**
- **Silent test errors** — failures inside tests were being swallowed instead of reported.
- IL emitter dropped interface implementations when `BaseClassName` named an interface
  rather than a class.
- Cached packages now resolve to the **latest cached version** instead of a hardcoded one.

## Changed

- `Compilation` split into partial class files by responsibility.
- `PrecompiledModuleInfo` consolidated into `CompiledModule`.
- All scripts now require **PowerShell 7.6.0+ (`pwsh`)**.
- Solution-wide cleanup pass.
